# Spec: shell-desktop — V1

Status: proposed · Module id: `shell-desktop` · Depends on: `shell-web` · Наследует [SPEC.md](SPEC.md)

## Objective

Нативное окно на Windows, macOS и Linux вокруг той же веб-сборки — и, что важнее,
сетевой слой без CORS, в котором подписки на ленты Google и iCloud наконец работают.

## Requirements

**Tauri 2.** `src-tauri/` с `tauri.conf.json`, `Cargo.toml`, минимальным `main.rs`.
Выбран вместо Electron: окно весит единицы мегабайт вместо ста с лишним, и системный
webview уже стоит в системе.

**Загрузка лент через нативный слой.** Главная причина существования этой обёртки.
Запрос идёт плагином `tauri-plugin-http` с явным списком разрешённых хостов в
`capabilities`, а не из webview. `ics-sync` получает это через ту же точку расширения,
что и уведомления: реализация загрузчика подменяется, модуль не правится.

**Разрешения — минимальные и перечисленные.** В `capabilities` только: доступ к сети для
хостов лент, диалог открытия и сохранения файла (импорт и экспорт `.ics` и дампа),
уведомления. Ни файловой системы целиком, ни запуска процессов, ни оболочки.

**Окно.** 1200×800 по умолчанию, минимум 480×600, размер и положение запоминаются.
На macOS — скрытый заголовок с нативными кнопками, чтобы интерфейс начинался от края.

**Автозапуск и трей** — не в V1, но окно не должно мешать их добавить: ничего не завязывать
на «приложение всегда видимо».

**Сборка здесь невозможна.** На машине разработки нет Rust (проверено: `cargo` отсутствует).
Поэтому результат модуля в V1 — конфигурация плюс раздел в `README.md` с тем, что поставить
(Rust toolchain, а на Windows ещё и Visual Studio Build Tools с C++) и какие команды запустить.
Бинарников в V1 нет, и выдавать конфиг за собранное приложение нельзя.

**Заявка на зависимость:** `@tauri-apps/cli`, `@tauri-apps/api`, `tauri-plugin-http`.
Требует одобрения по границе «Ask first».

## Success Criteria

1. `src-tauri/tauri.conf.json` присутствует и проходит проверку схемы.
2. `capabilities` перечисляет ровно: сеть для хостов лент, диалоги файлов, уведомления.
3. `README.md` содержит список инструментов и команды `npm run tauri dev` / `tauri build`
   с указанием, что на этой машине они не запускались.
4. Веб-сборка открывается из `file://` без ошибок путей — предпосылка для обёртки, уже покрыта
   критерием 7 в [SPEC-shell-web.md](SPEC-shell-web.md).
5. Точка подмены загрузчика лент существует в `ics-sync` и используется обёрткой
   без правок самого модуля.

**Непроверяемое здесь и помеченное как таковое:** запуск окна, работа подписок без CORS,
сборка установщиков. Это проверяется на машине с Rust.

## Boundaries (delta)

- **Never:** просить разрешения шире перечисленных; каждое новое — отдельное решение.
- **Never:** утверждать, что десктоп собран или проверен, пока не было прогона на машине с Rust.

## Out of Scope

- Подписанные установщики и автообновление — нужны сертификаты; V2.
- Иконка в трее, автозапуск, глобальные горячие клавиши — V2.
- Единое меню приложения macOS — V2.
