# Spec: shell-web — V1

Status: proposed · Module id: `shell-web` · Depends on: `ui` · Наследует [SPEC.md](SPEC.md)

## Objective

Приложение, которое ставится из браузера и работает без сети. Это основная платформа V1
и база для обёрток десктопа и мобильных.

## Requirements

**Манифест и service worker** — через `vite-plugin-pwa`, конфигурация уже в `vite.config.ts`:
`registerType: 'autoUpdate'`, `navigateFallback` на `index.html`, прекеш всей сборки.

**Иконки.** Нужны настоящие файлы: `icons/icon-192.png`, `icons/icon-512.png`,
`icons/icon-512-maskable.png` и `favicon.svg`. Maskable — с запасом по краям, иначе
Android обрежет. Генерируются из одного SVG скриптом, а не руками.

**`base: './'`** — относительные пути в сборке, чтобы та же сборка открывалась из `file://`
внутри Tauri и Capacitor. Уже выставлено.

**Офлайн.** После первой загрузки приложение открывается и полностью работает при выключенной
сети: данные в IndexedDB, код в прекеше. Недоступно офлайн только обновление лент — оно
показывает ошибку и оставляет прошлые события.

**Обновление версии.** `autoUpdate` ставит новый service worker, но перезагружать страницу
под руками пользователя нельзя. Поэтому: при готовности обновления — ненавязчивая плашка
«Доступна новая версия · Обновить».

**Установка.** Плашка с предложением установить — по событию `beforeinstallprompt`, и только
после второго визита: предложение при первом знакомстве отклоняют не читая. Отказ запоминается.

**Безопасная зона.** `viewport-fit=cover` уже в `index.html`; отступы через `env(safe-area-inset-*)`,
иначе на телефоне с вырезом нижняя панель уедет под системную полосу.

## Success Criteria

1. `npm run build` даёт сборку с `manifest.webmanifest`, service worker и всеми иконками.
2. Lighthouse в разделе PWA не показывает ошибок по манифесту и service worker.
3. Приложение устанавливается в Chrome и открывается отдельным окном без адресной строки.
4. После первой загрузки и выключения сети приложение открывается и позволяет создать событие.
5. Созданное офлайн событие остаётся после перезагрузки.
6. Плашка обновления появляется при новой сборке и обновляет по кнопке, а не сама.
7. Открытая сборка из `file://` не падает на путях к ресурсам (проверка `base: './'`).
8. На iPhone в Safari нижняя панель не перекрыта системной полосой.

## Boundaries (delta)

- **Never:** перезагружать страницу без действия пользователя.
- **Never:** кешировать ответы лент как `CacheFirst` — пользователь получит вчерашние события
  и не поймёт почему. Только `NetworkFirst`, как уже настроено.

## Out of Scope

- Web Push — нужен сервер и ключи VAPID; V2.
- Публикация в Play Store через Bubblewrap/TWA — V2.
- Периодическая фоновая синхронизация (`Periodic Background Sync`) — поддержана только в Chrome; V2.
